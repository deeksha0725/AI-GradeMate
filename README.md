# AI GradeMate 🎓

### AI-Powered Automated Assessment and Intelligent Grading Assistant

AI GradeMate is an AI-powered application designed to help educators evaluate subjective student answers efficiently, consistently, and transparently.

## 🚀 Features

- AI-powered subjective answer evaluation
- Rubric-based grading and partial credit
- Automated feedback and improvement suggestions
- PDF text extraction
- Teacher score override and moderation
- Performance dashboard
- Evaluation history
- Teacher audit log with SQLite persistence

## 🛠️ Tech Stack

- Python
- Streamlit
- Groq API
- SQLite
- PyMuPDF
- Pandas
- Plotly

## ⚙️ Installation

1. Clone the repository:
   `git clone https://github.com/deeksha0725/AI-GradeMate.git`

2. Install dependencies:
   `pip install streamlit groq pymupdf pandas plotly python-dotenv`

3. Create a `.env` file and add:
   `GROQ_API_KEY=your_api_key`

4. Run the application:
   `streamlit run app.py`

## 🎯 Project Goal

To reduce manual grading effort, improve assessment consistency, and provide actionable feedback to students while keeping educators in control.
